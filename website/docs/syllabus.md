# Syllabus

## 核心依据

当前课程以 syllabus/2026-spring/传感器与检测技术授课计划_升级版 .pdf 为唯一核心依据。

## 课程目标

- 建立面向具身感知工程的传感器系统认识框架。
- 能从 Datasheet 出发理解精度、噪声、稳定性与误差传播。
- 掌握嵌入式驱动、GNSS/RTK、IMU 标定、磁力计校准、压力高度解算等关键工程链路。
- 能将 ESKF、姿态估计和 AI 增强方法用于产品级综合设计。

## 考核构成

- 平时实验：20%
- 标定专报：15%
- 论文研读：10%
- 综合设计：50%
- 数字化资产沉淀要求纳入过程管理

- 标定专报
