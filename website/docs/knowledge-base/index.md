## Core Formula Reminders

- Absolute error: `\Delta x = x_m - x_t`
- Relative error: `\delta = \Delta x / x_t`
- Bridge output (small-signal): `V_o \approx (\Delta R / 4R) V_{exc}`

## Common Misconceptions

1. High precision always means high accuracy (false).
2. Calibration once is enough for all conditions (false).
3. Higher sampling rate always improves measurements (false).
