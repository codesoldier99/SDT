# 传感器与检测技术

本课程网站围绕官方授课计划构建，当前版本对应 2026 Spring 课程重构周期，聚焦具身感知工程、工业指标分析、驱动开发、高精度定位、惯性测量、数据融合与产品级综合设计。

## 官方课程结构

- 总学时：36
- 讲课：22 学时
- 实验：8 学时
- 综合设计：6 学时
- 考核方式：考查

## 当前重构原则

1. 官方授课计划 PDF 是唯一核心依据。
2. 原始素材保留在原目录，不直接复制历史材料进入正式课程产物。
3. 网站、讲义、实验、资源与视频统一按模板生产。
4. 每学年保留版本快照，支持持续更新。

## 核心模块

- 具身感知工程导论
- 传感器特性与 Datasheet 分析
- 驱动开发与 AI 协作范式
- GNSS/RTK 与高精度定位
- IMU 标定与误差建模
- 磁传感器与信号完整性
- 压力传感器与高度解算
- ESKF 与姿态融合
- AI 增强感知算法
- 产品级综合设计与答辩
