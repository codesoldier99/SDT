# Labs

当前课程设置 6 个实验和 1 个综合设计任务，覆盖从硬件链路、驱动开发到标定、定位和融合的完整工程流程。

## 实验列表

1. 硬件链路打通
2. 嵌入式实时性测量
3. GNSS 驱动与 RTK 对比
4. IMU 完整标定
5. 磁力计驱动与标定
6. 气压计高度解算

## 综合设计

- 目标：完成产品级传感系统设计与答辩
- 产出：Spec、原理图、Gerber、代码、演示视频、总结报告

## 统一实验模板

- 目标
- 预习
- 设备
- 步骤
- 数据分析
- 报告模板
- 评分细则
- 安全提示
- 排障建议

详细模板见仓库中的 labs/template/lab-template.md。
