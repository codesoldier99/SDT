# Laboratory Assignments

Design each lab as a 2-hour session.

## Required sections for every lab

1. Objective
2. Pre-lab preparation
3. Equipment list
4. Step-by-step procedures
5. Data analysis requirements
6. Report template
7. Grading rubric
8. Safety guidelines
9. Troubleshooting tips

Include both:
- hardware experiment tasks
- Python simulation tasks

## Suggested lab sequence

- Lab 1: Intro instrumentation + safety
- Lab 2: Temperature sensor calibration
- Lab 3: Strain gauge bridge measurement
- Lab 4: Capacitive sensor characterization
- Lab 5: LVDT displacement measurement
- Lab 6: Photoelectric sensing and noise filtering
- Lab 7: Gas sensor response curve analysis
- Lab 8: MEMS IMU signal processing
- Lab 9: IoT sensor node data logging
- Lab 10: Final integrated sensing mini-project
