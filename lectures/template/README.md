# Lecture Template Guidance

Use this template for each lecture deck (PPT/PDF).

## Mandatory Slide Flow

1. Title slide
2. Learning objectives
3. Theoretical foundation
4. Working principles
5. Practical examples
6. Summary
7. Homework

## Quality Checklist

- [ ] Include high-quality diagrams
- [ ] Include circuit schematics
- [ ] Include real sensor photos
- [ ] Add speaker notes on every slide
- [ ] Keep language concise for undergraduates
- [ ] Add latest industry examples during annual refresh
