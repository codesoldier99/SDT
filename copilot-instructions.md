# Copilot Instructions for SDT Course Maintenance

## Primary Source of Truth

Always align generated content with files in:

- `/syllabus`
- `/lectures/2026-spring`
- `/labs`

## Teaching Style

- Audience: undergraduate engineering students
- Language: clear, concise, practice-oriented
- Balance: physics theory + circuit implementation + engineering applications
- Include bilingual support (English/Chinese) where practical

## Lecture Slide Requirements

For each lecture, follow this order:
1. Title
2. Learning objectives
3. Theoretical foundation
4. Working principles
5. Practical examples
6. Summary
7. Homework

Each lecture should include:
- real sensor images
- circuit/signal-conditioning schematics
- speaker notes with teaching tips and timing suggestions

## Annual Update Guidance

When preparing a new term:
- copy previous term materials into a new year-term folder
- keep old folders unchanged as archive
- update examples with emerging topics (MEMS, IoT, AI sensing, LiDAR)

## Lab Content Requirements

Each lab must include:
- objective
- pre-lab tasks
- equipment list
- procedure
- data analysis
- report template
- grading rubric
- safety and troubleshooting

Include both hardware experiments and Python simulation components.
