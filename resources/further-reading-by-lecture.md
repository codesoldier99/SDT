# Further Reading by Lecture Topic

| Topic Group | Suggested Reading |
|---|---|
| Measurement fundamentals | Bentley, *Principles of Measurement Systems* |
| Resistive/capacitive/inductive sensors | Fraden, *Handbook of Modern Sensors* |
| Temperature sensing | TI application notes on RTD/thermocouple front ends |
| Optical/photoelectric sensing | Analog Devices optical sensing notes |
| Signal conditioning | TI Precision Labs and ADI design guides |
| Calibration/error analysis | Morris & Langari, *Measurement and Instrumentation* |
| MEMS and smart sensors | Gardner et al., *Microsensors, MEMS, and Smart Devices* |
| IoT sensor systems | Manufacturer design guides and open IoT docs |
| AI-enabled detection | Recent open-access review papers on ML for sensing |
| LiDAR | Nitaigour, *LiDAR: Technologies and Systems* |
