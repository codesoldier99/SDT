# Course Overview

## Positioning

Sensors and Detection Technology is a core engineering course connecting:

- theoretical physics
- electronic circuits
- real engineering systems

## Learning Outcomes

By the end of the course, students can:

1. Explain key sensing principles (resistive, capacitive, inductive, optical, thermal, magnetic, electrochemical).
2. Design sensor interface and signal-conditioning circuits.
3. Evaluate static/dynamic performance and uncertainty.
4. Build and test sensor systems for practical use cases.
5. Analyze modern trends including MEMS, IoT sensing, AI-enabled detection, and LiDAR.
