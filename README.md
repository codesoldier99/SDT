# Sensors and Detection Technology (SDT)

This repository maintains teaching materials for the undergraduate **Sensors and Detection Technology** course.

## Repository Structure

```text
sensors-and-detection-technology/
├── syllabus/              # Course syllabus and teaching plan
├── lectures/              # Lecture slides (PPT/PDF)
│   ├── 2026-spring/       # Current year materials
│   ├── 2025-spring/       # Previous year archives
│   └── template/          # PPT template and lecture structure
├── labs/                  # Laboratory assignments
├── website/               # MkDocs Material website source
├── resources/             # Reference books, datasheets, papers
├── videos/                # Video links and custom video scripts
├── assignments/           # Homework and project assignments
└── exams/                 # Past exams and solutions
```

## Quick Start

1. Start from the teaching plan in `/syllabus`.
2. Create each lecture using `/lectures/template`.
3. Publish updates through `/website`.
4. Archive prior terms under `/lectures/<year-term>`.

## Website

The website is built with MkDocs Material and includes:

- Syllabus
- Schedule
- Lectures
- Labs
- Resources
- FAQ
- Announcements
- Searchable knowledge base
- Video recommendations

See `/website/README.md` for local build and deployment instructions.
