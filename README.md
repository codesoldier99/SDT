# 传感器与检测技术

本仓库用于重构与持续维护“传感器与检测技术”课程资料，当前以官方授课计划 PDF 为唯一核心依据，围绕课程网站、讲义模板、实验模板、参考资料和年度版本化发布建立统一工作流。

## 当前课程基线

- 依据文件：传感器与检测技术授课计划_升级版 .pdf
- 总学时：36 学时
- 结构：讲课 22 学时 + 实验 8 学时 + 综合设计 6 学时
- 当前教学主线：具身感知工程、工业指标分析、GNSS/RTK、IMU 标定、ESKF 融合、AI 增强感知、PCB 工程化

## 仓库结构

- syllabus/：官方授课计划与课程说明
- lectures/：按学年学期版本化的讲义、PPT 规划与模板
- labs/：实验讲义、实验模板与综合设计说明
- website/：Docusaurus 课程网站源码
- resources/：书目、知识库、资料模板与外部资源索引
- videos/：推荐视频、脚本模板与自制视频规划
- assignments/：作业与课程项目提交说明
- exams/：考查与归档说明

## 迁移边界

- 第一阶段仅迁入官方升级版授课计划 PDF。
- 原始课件、历史代码、器件 PDF、学生归档、成绩和照片不直接迁入本仓库。
- 其余课程内容全部依据官方授课计划重新生成，并按统一模板沉淀。

## 课程实施概况

当前课程网站和内容结构基于 18 个两学时教学单元搭建：

1. 绪论：具身感知工程导论
2. 传感器特性与 Datasheet 分析
3. 驱动开发与 AI 协作范式
4. 实验一：硬件链路打通
5. 实验二：嵌入式实时性
6. GNSS 与高精度定位
7. 实验三：GNSS 驱动与 RTK
8. 惯性传感器原理与建模
9. 实验四：IMU 完整标定
10. 磁传感器与信号完整性
11. 实验五：磁力计驱动与标定
12. 压力传感器原理及应用
13. 实验六：气压计高度解算
14. 数据融合（一）：ESKF
15. 数据融合（二）：算法对比
16. 数据融合（三）：AI 增强
17. 综合设计：产品级系统
18. 答辩与总结

## 网站与发布

课程网站基于 Docusaurus 构建，支持：

- 中文优先导航
- 深浅色模式
- GitHub Pages 自动部署
- 课程公告
- 后续学年版本归档

本地运行：

```bash
cd website
npm install
npm start
```

生产构建：

```bash
cd website
npm run build
```

## 更新方式

1. 官方授课计划发生调整时，先更新 syllabus/ 中的基线文件与摘要。
2. 每学年在 lectures/、labs/、videos/ 下建立新版本目录。
3. 网站文档按授课计划同步更新，并在版本发布时保留旧学年快照。
4. 新技术专题优先进入模板与知识库，再进入正式课件和实验。

## 贡献方式

- 教师或行业工程师可通过 Pull Request 提交内容改进。
- 新内容应先遵循根目录 copilot-instructions.md 的生成规范。
- 涉及课程结构调整时，应先以官方授课计划 PDF 为准更新网站和模板。
